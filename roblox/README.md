# Open Planet — версия для Roblox

Здесь находится файл игры **OpenPlanet.rbxl** для Roblox Studio.

## Как открыть игру

1. Скачай [OpenPlanet.rbxl](./OpenPlanet.rbxl). На GitHub открой файл и нажми **Download raw file**.
2. Запусти Roblox Studio.
3. Выбери **File → Open from File** и открой скачанный файл.
4. Нажми **Play**, чтобы проверить игру в Studio.

GitHub хранит файл игры. Чтобы играть именно на платформе Roblox, нужно отдельно опубликовать игру через Roblox и выполнить требования платформы.

В этой папке опубликована сохранённая версия файла OpenPlanet-Clean.rbxl от 14 октября 2026 года.

## Браузерная версия

В основной папке этого проекта находится отдельная браузерная версия Open Planet.
